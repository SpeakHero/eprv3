## 二、发现的问题（按严重程度）

### P0-1 独立库租户保存模块授权返回 500（阻塞）

- **现象**：租户详情 → 模块授权 → 勾选变更 → 保存授权，`PUT /api/portal/admin/tenants/{id}/modules` 返回 HTTP 500。
- **响应体**：
  ```json
  {"success":false,"code":"INTERNAL_ERROR","message":"服务器内部错误：The database operation was expected to affect 1 row(s), but actually affected 0 row(s); data may have been modified or deleted since entities were loaded. ...optimistic concurrency..."}
  ```
- **范围判定**：`qlx-demo`（独立库，当前仅 support 已授权）稳定复现；`upg-smoke`（共享库）同接口授权/回收均返回 200 并正确写入 `por_license_records`。
- **定位线索**：异常为 EF Core `DbUpdateConcurrencyException`；[PortalTenantAdminService.SaveLicenseAsync](file:///e:/ERPv2/eprv3/src/Qlx.Modules.Portal/Services/PortalTenantAdminService.cs#L243-L319) 在 qlx-demo 场景仅涉及"新增 bas 行 + 插入授权记录"，理论上无 UPDATE 路径，需排查 `Tenant` 聚合跟踪状态、触发器或独立库租户的关联写入。DB 直查 `por_tenant_modules`：qlx-demo 仅 1 行 support（Status=1），`LicensedAt` 为 `+08:00` 偏移（其余租户为 `+00:00`），疑似历史种子数据时区写入不一致，建议一并核查。
- **影响**：独立库租户无法变更模块授权，属核心管控功能阻断。

### P1-1 租户/用户列表分页总数恒显示「共 0 条」

- **现象**：租户列表 8 行、用户列表 7 行均正常渲染，但分页区显示「共 0 条」（见截图 02、06、07）。
- **根因**：前端契约字段不一致——[useCrudTable.ts:58](file:///e:/ERPv2/eprv3/src/Qlx.Web/src/composables/useCrudTable.ts#L58) 读取 `result.totalCount`，类型 [types/admin.ts:18](file:///e:/ERPv2/eprv3/src/Qlx.Web/src/types/admin.ts#L18) 亦声明 `totalCount`；但 `/api/portal/admin/tenants` 与 `/api/portal/admin/users` 实际返回 `{ items, total }`（实测 total=8）。对比：`/api/portal/admin/roles` 返回的是 `totalCount`——**后端分页响应契约不统一**是根因。
- **修复建议**：统一后端 `PortalPagedResult` 字段命名（或前端适配层做映射），并补契约测试防回归。

### P2-1 门户角色管理无导航入口

- `/portal/roles` 路由存在、页面功能完整（新建/详情/删除实测通过），但门户管理侧栏（租户管理/用户管理/模块许可/审计中心/系统配置）与工作台常用功能均无入口，只能直输 URL 到达。功能被"埋藏"，需求侧需确认是否本期开放；若开放应补导航。

### P2-2 工作台「信息中心」按钮点击无任何响应

- 工作台顶栏「信息中心」按钮点击后无弹层、无跳转、无提示（URL 保持 /workbench）。疑似占位未接线，建议挂接消息中心或显式禁用。

### P2-3 favicon.ico 404

- 全站缺失 favicon，每个页面加载产生一条 404。

### P3-1 「审计中心 / 系统配置」占位菜单可点击但零反馈

- 侧栏占位项带 `is-placeholder` 样式但 `disabled=false`，点击后无跳转无提示，用户无法感知是"未开放"。建议置灰禁用或点击提示"后续阶段开放"。

### P3-2 全平台授权记录表缺少租户列

- 模块许可页底部「授权记录（17）」仅含 模块/操作/变更说明/操作人/时间，无租户名称列，平台级审计场景无法直接定位记录归属租户（需回租户详情页查看）。建议增加租户列。

### 观察项（未定论）

- 列表页 停用/启用、重置密码成功后未观察到成功 toast（源码中 `ElMessage.success` 存在，可能因 toast 3 秒生命周期错过观察），建议人工复验一次提示可见性。

4. **P3**：占位菜单禁用化；授权记录补租户列。
