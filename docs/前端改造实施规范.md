## §0.5 公共层优先原则（强制执行）

> **来源**：项目记忆「开发租户自管理域前端时优先开发公共代码/组件，注重细节及代码/组件的复用」
> **与后端对齐**：后端全局强制规则 `.trae/rules/global-cache-layering-standard.md` 已确立 B-2（展示类计算前后端职责边界）——前端树组装/格式化/枚举映射/快捷挑选等必须在前端公共层，禁止后端输出展示态

### 核心原则

| 优先级 | 动作 | 示例 |
|---|---|---|
| ⭐⭐⭐ 最优先 | **复用已有公共组件/工具/类型**，禁止在新页面重复实现 | QlxSearchBar / QlxDataTable / useCrudTable / format.ts 全部先查已有能力 |
| ⭐⭐ | **可独立于页面的纯函数/类型先抽公共层**，再被 store/页面消费 | buildTreeForTenant 先放 `utils/menuTree.ts`，menuStore 只调不持有组装逻辑 |
| ⭐ | 多个 store / 页面会用到的**状态片段 / 判定逻辑抽 composable** | hasPermission + isTenantAdmin + isPortalAdminMode 三条件 → `composables/usePermission.ts` |

|---|---|---|---|

### 1.1 JWT Payload 解码器
**文件**：`src/Qlx.Web/src/core/jwt.ts`（新建）

**职责**：Base64Url 解码 JWT payload 部分（前端不验签，后端 OpenIddict 已验）

```typescript
export interface TokenClaims {
  sub?: string                // 用户身份标识
  tenant_id?: string          // 租户混淆串（租户级 Token 有）
  qlx_member_role?: string    // TenantAdmin / OrdinaryMember（前端映射为 memberRole）
  qlx_data_scope?: string     // All / DeptAndChildren / Dept / Self
  qlx_data_scope_dept?: string
  qlx_permissions?: string    // 逗号分隔权限码
  qlx_portal_admin?: string   // "1"（门户管理员身份 Token）
  [key: string]: unknown
}

/** 解码 JWT payload；格式非法或 base64 解码失败返回 null。 */
export function decodeJwtPayload(token: string): TokenClaims | null {
  // 1. token.split('.')[1] → payload 段
  // 2. Base64UrlDecode（替换 -→+ /→_ → 补 =）
  // 3. JSON.parse → TokenClaims
  // 4. 统一字段名映射：qlx_member_role → memberRole, qlx_permissions → permissions
}
```

**单测覆盖**（`__tests__/jwt.spec.ts`）：
- 合法三段 JWT
- 缺段 / 非法格式 / 空串
- Base64Url 特殊字符（-/=）
- claims 全部字段提取正确
- 缺省字段返回 undefined（不抛错）

### 1.2 auth store 扩展
**修改文件**：`src/Qlx.Web/src/stores/auth.ts`

#### 新增 state
```typescript
memberRole: ''                // 'TenantAdmin' / 'OrdinaryMember' / ''（门户模式）

```

#### 新增 getters
```typescript

hasPermission: (state) => (code: string) =>
  state.isTenantAdmin                                    // TenantAdmin 零计算旁路
  || state.portalAdminMode                               // 门户管理模式零计算旁路
```

#### 解析时机（修改现有 action）

| 时机 | 触发 | 行为 |
|---|---|---|
| `signIn()` 成功后 | 拿到身份级 access token | decode 身份 Token → 预填 permissions（门户管理员 Token 可能无此 claim，保持空） |
| `enterTenant()` | 拿到新租户 Token | decode 租户 Token → 填 memberRole / permissions / dataScope；clearSession 旧值 |
| `enterPortalAdmin()` | 拿到/复用身份 Token | decode 身份 Token → 填 permissions（身份级） |
| `refreshTenant()` | 租户续期成功 | decode 新租户 Token payload → 更新 claims |
| `refreshIdentity()` | 身份续期成功 | decode 新身份 Token payload → 更新 claims |
| `reset()` | 登出/会话清空 | 同步清空新字段 |

#### persist/loadSession 同步
`core/session.ts` 的 `PersistedSession` 接口补充新字段 → `saveSession` / `loadSession` 自动包含。

#### 本次新建公共层：`src/Qlx.Web/src/utils/menuTree.ts`（先于 menuStore 开发）
```typescript
/** 纯函数：零副作用、独立可单测；菜单过滤 + 树形组装 + 导航分组聚合。 */
export function buildTreeForTenant(
  navGroups: NavGroupDTO[],
  menus: MenuFlatDTO[],
  licensedModules: string[],
  permissions: string[],
  memberRole: string,
  portalAdminMode: boolean,
): MenuGrouped[]
```

#### 过滤规则（menuTree.ts 内实现）
```
1. 模块许可裁剪：menus.filter(m => licensedModules.includes(m.moduleCode))
2. 权限裁剪（TenantAdmin / portalAdminMode 跳过此步）：
     menus.filter(m => !m.requiredPermissionCode || permissions.includes(m.requiredPermissionCode))
3. 树组装：按 parentCode → Map<parentCode, MenuTree[]> → 挂载到 root
4. 导航分组聚合：navGroups.map(g => g.moduleCodes.split(',').trim().filter(Boolean))
   → 匹配 menus.map(m => m.moduleCode) → 放入该组
```

#### 降级策略
- API 调用失败 → 保留空 builtGroups + 现有 `data/navigation.ts` 作为 UI 兜底
- 首次进入（restore 后）若 rawMenus 空 → 后台静默 loadFromApi

#### 单测覆盖（`__tests__/menu.spec.ts`）
- 模块许可裁剪生效
- 权限裁剪 + hasPermission 精确匹配
- TenantAdmin / portalAdminMode 跳过权限裁剪
- parentCode 树形组装正确（深层嵌套 + 循环引用防护）
- GroupCode 聚合正确（一菜单匹配多分组？设计约束：moduleCode 唯一归属一个 Group）

### 1.5 v-permission 指令
**新建文件**：`src/Qlx.Web/src/directives/permission.ts`
**注册**：`main.ts` 中 `app.directive('permission', vPermission)`

```typescript
export const vPermission: Directive<HTMLElement, string | string[]> = {
  mounted(el, binding) {
    const auth = useAuthStore()
    if (auth.isTenantAdmin || auth.portalAdminMode) return
    const codes = Array.isArray(binding.value) ? binding.value : [binding.value]
    const has = codes.some(c => auth.permissions.includes(c))
    if (!has) el.parentNode?.removeChild(el)
  }
}
```

**单测覆盖**（`__tests__/permission.spec.ts`）：
- 单码无权限 → 移除
- 多码 OR 语义（任一命中 → 保留）
- TenantAdmin 旁路不移除
- portalAdminMode 旁路不移除
