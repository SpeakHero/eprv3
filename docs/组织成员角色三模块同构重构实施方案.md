## 0. 编制动因与核心结论

### 0.1 动因

1. 同一业务两套实现：租户侧「角色权限」为左列表+三 Tab 形态，门户侧为表格+两个独立路由页，组件零复用、样式体系不一（门户页存在散装 utility class，未用 qlx-token）。
2. 租户侧真实联调存在**功能性缺口**：角色「功能权限 / 角色成员」Tab 无回显端点、组织成员数恒为 0、岗位启停/重发邀请/批量导入/登录日志为 mock 占位。
3. 门户侧按钮级权限码（`portal.role.create/.delete`）与后端种子权限点（`portal.role.menu/.action`）不匹配，按钮指令永不命中。
4. HTTP 客户端双轨：`core/http.ts`（拦截器自动注入 Token）与 `api/portal-role.ts`/`api/portal-permission.ts`（私有 axios 实例 + 手工 Bearer）并存。

### 0.2 核心结论

1. **一套组件族 + 场景适配器（Adapter）**：页面层只组合组件与 adapter，不出现任何 `/api/tenant`、`/api/portal` 路径分支；场景差异（数据范围、编码规则、内置锁定策略、成员模型）全部由 `caps` 参数表达。
2. **后端最小补全**：仅补 10 项缺口（§5 B-1~B-10），不新增业务域；所有补全字段为扁平原始字段/聚合计数，严格遵守 B-2（不做展示拼接）。
3. **门户角色页改为与租户同骨架**（左角色列表+右三 Tab），撤销两个独立分配路由页（保留重定向一个版本周期）。
4. **公共层先行**：适配层与组件族先于页面交付（T2→T3→T4/T5/T6），页面批次只做组装。

## 2. 总体约束（必达）

1. **公共层优先**（强制）：适配器、类型、枚举字典、组件族全部先于页面交付；页面层禁止新增可复用逻辑的私有实现。
2. **B-x 合规**：后端不下发展示产物；树组装/名称 join/枚举映射/格式化只在前端公共层；聚合计数（memberCount/permissionCount）属原始字段由后端单 SQL 聚合下发（禁 N+1）。
3. **V-x 合规**：前端校验仅 UX 层；后端独立完整校验现状已具备，补全端点同等执行；后端 400/409 消息前端直显。
4. **工程基线不回退**：后端 build 0 警告 0 错误、测试只增不减；前端 `npm run build` 0 错误、`vitest` 全绿。
5. **串行批次**：按 §10 批次顺序推进，每批次出口条件达成（审查+编译+测试）才进入下一批次。

## 4. 目标架构

### 4.1 分层与依赖方向

```
页面层  views/tenant/Tenant*View.vue、views/portal/PortalRoleAdminView.vue
   │（只组合，无 API 字面量、无展示计算）
组件族  components/org-admin/、components/member-admin/、components/role-admin/
   │（props=扁平数据+adapter+caps；内部只做交互，不做请求）
适配层  api/adapters/{orgAdmin,memberAdmin,roleAdmin}.ts（接口 + tenant/portal 实现）
   │
基础层  core/http.ts、types/org-admin.ts、types/tenant.ts（字典）、composables/、directives/
```

### 4.2 场景差异矩阵（caps 表达）

| 能力 | 租户场景 | 门户场景 |
|------|----------|----------|
| 数据范围（dataScope） | 有（含 Custom） | 无 |
| 角色编码规则 | `/^[\u4e00-\u9fa5A-Za-z0-9_]{2,32}$/` | `/^portal\.[a-z0-9_\-]+$/`（≤64） |
| 内置角色锁定 | 权限只读、成员可配、可编辑描述 | 全锁（不可编辑/删除/分配） |
| 成员模型 | tenant_members（姓名/账号/组织） | portal_users（登录账号/显示名） |
| 权限定义源 | GET `/api/tenant/permissions`（PermissionGroupRow） | GET `/{id}/permission-options`（PermissionOption，适配层按 ModuleCode/GroupName 归一为 PermissionGroup） |

### 4.3 适配器契约（`api/adapters/roleAdmin.ts`）

```ts
export interface RoleItem {
  id: string; code: string; name: string; description: string
  isBuiltin: boolean; dataScope: DataScope | null
  memberCount: number; permissionCount: number; updatedAt: string
}
export interface MemberOption { id: string; name: string; account: string; orgName?: string }
export interface RoleAdminCaps {
  dataScope: boolean
  codePattern: RegExp; codeHint: string
  builtinLock: 'permissions' | 'all'
}
export interface RoleAdminAdapter {
  caps: RoleAdminCaps
  listRoles(): Promise<RoleItem[]>
  saveRole(id: string | null, p: { code: string; name: string; description: string; dataScope: DataScope | null }): Promise<RoleItem>
  deleteRole(id: string): Promise<void>
  fetchRolePermissions(id: string): Promise<string[]>
  saveRolePermissions(id: string, codes: string[]): Promise<void>
  fetchRoleMemberIds(id: string): Promise<string[]>
  fetchMemberOptions(): Promise<MemberOption[]>
  saveRoleMembers(id: string, ids: string[]): Promise<void>
  fetchPermissionGroups(): Promise<PermissionGroup[]>
}
export function createTenantRoleAdminAdapter(): RoleAdminAdapter   // /api/tenant/roles/*
export function createPortalRoleAdminAdapter(): RoleAdminAdapter   // /api/portal/admin/roles/*
```

orgAdmin / memberAdmin 适配器同构（接口 + tenant 实现；门户无组织域不实现 orgAdmin）。

### §5.1 T1 实施偏差记录（2026-10-23 完成后回写，以代码为准）

| 项 | 原方案描述 | 实际落地 | 原因 |
|---|---|---|---|
| B-3 聚合写法 | LEFT JOIN 分组 COUNT | **相关标量子查询投影**（`SELECT ..., (SELECT COUNT...)`）单往返 | 双 GroupJoin 投影在 Sqlite 不可翻译；子查询形式 SQL Server/Sqlite 全提供程序可译，同样禁 N+1 |
| B-8 数据源 | 门户库登录审计按 portalUserId+tenantId 手动过滤 | **租户库 `log_login`**（TenantLogDbContext 全局 TenantId 过滤自动生效，按 LoginAccount 过滤，雪花 EventId 倒序） | 登录审计实际分流：租户登录成功落租户库 log_login（无 PortalUserId 列），门户库 plog_operation 只承载门户登录/失败 |
| B-7 导入链路 | 复用 2F ImportExportService（文件流/模板码） | **Service 内行级处理**（预载组织/角色字典内存匹配，逐行独立提交天然隔离） | 前端契约为解析后的 JSON 行数组（`ImportMemberRow[]`），非文件流；逐行独立提交即行级隔离，无需事务保存点 |
| B-6 通知通道 | 重置邀请时间戳 + IMessageService 模板通知 | **PushAsync 站内直推**（收件人=混淆门户用户 Id，BizRef=TenantMemberInvite）；无实体字段可重置（JoinAt 待接受时写入） | SendTemplateAsync 在模板缺失时抛 NotFoundException，依赖模板种子；直推零模板依赖、不新增通道（D7 本意保留） |
| B-10 门户角色挂载 | 权限点挂内置管理员角色 | **仅声明 Manifest 权限点**（portal.role.create/.update/.delete/.assign + portal.role.menu/.action）自动同步 | 代码核实不存在内置门户管理员角色种子；qlxadmin 走 IsPortalAdmin 零计算旁路，权限点供自定义角色分配 |
| 附带修复 | — | `GetMemberDetailAsync` 增加越租户 404 守卫（`GetTenantMemberOr404Async`，重发邀请/登录日志/详情统一走） | 既有缺口：Portal 侧 GetMemberDetailAsync 无租户过滤，存在越权探测面 |

T1 出口已达成：`dotnet build` 0 警告 0 错误；全量测试 823 绿（新增 21：Bas 17 + Portal TenantMemberAdmin 3 + 计数/越权/导入分支），基线不回退。
