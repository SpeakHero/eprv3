### 3.3 用例场景矩阵（按用户要求四类）

#### 正常输入场景（示例）

- 登录成功：清失败计数、写 LastLoginAt、首登激活、sub 混淆、token_kind=identity、租户列表参数、成功审计
- 门户管理员旁路：`is_portal_admin=1`、无权限枚举、响应含 PortalAdmin 标记
- 普通用户权限聚合（查询注册 / 未注册两分支）
- 刷新成功：重签 claims 与响应参数
- 租户上下文成功：单角色自动锁定、权限码写入、模块枚举（仅 Enabled）、租户上下文写入-恢复序列 `[t,0,t,0]`、合并 TokenVersion
- 静默续期成功：真实 JWE 解密 + 验签 + 宽限期内过期换新
- 密码哈希升级（`SuccessRehashNeeded` → 重签落库）

#### 边界值场景

- 凭证长度 128（通过）/ 129（拒绝）
- AccessToken 有效期 1 / 1440 分钟边界；Refresh 1 / 90 天边界
- 锁定阈值恰好达标（第 N 次失败即锁，第 N+1 次正确密码仍被拦）
- IP 限流恰好 20 次跨账号封禁（第 21 次任何账号均被前置拦截）
- 密码 MinPasswordLength 6 / 128 边界；NeverRepeat 0 / 24 边界；Retention ≥ Repeat 约束
- jti 恰好为空 / 空白串 / 正常值；exp 恰好过期 / 未来 / 非法格式

#### 异常输入场景

- null principal / null user / null bearerToken / 空 grant 参数（`ArgumentNullException` / `ArgumentException`）
- 畸形 JWT（`not-a-jwt`）、错误 Issuer 的合法签名 JWE、超宽限期过期令牌
- 混淆 ID 不可解码（`bad-tenant`）、tenant_id=0 / 负数、member_role_id 无效
- token_kind 错用（identity ↔ tenant 互斥）、token_kind claim 完全缺失
- 凭证注入样本（`admin'--`）入键无明文泄露

#### 错误处理场景

- 统一失败文案防枚举：账号不存在 / 密码错误 / 账号锁定 / IP 封禁 四者响应完全一致
- 停用账号独立文案（区别于统一文案，供客服引导）
- 无租户三分支消息：未关联 / 待激活 / 成员停用 / 租户停用
- 成员四态异常（missing / disabled / pending / tenant-disabled）在 EnterTenant 与 Renew 双侧
- Token 版本失效：`tv_u` / `tv_m` 不匹配 → 「登录状态已失效」
- 越权角色拒绝、多角色未选拒绝、角色失效（声明角色已不在成员角色列表）
- 审计写入失败不抛（平台 / 租户两侧降级）
- 认证服务返回 null（违反契约）→ 控制器视为认证失败（防御分支）

## 四、内部逻辑正确性验证

| 验证项 | 方法 | 结果 |
|---|---|---|
| 算法实现 | 密码哈希 PBKDF2 校验 / 升级重签；SHA256 入键哈希（32 位小写 hex）；JWE 解密 + JWS 验签（HmacSha256 / Aes256KW / Aes256CbcHmacSha512） | ✅ |
| 数据流转 | 登录成功 → 计数清除 + 激活 + 审计 + LastLoginAt 落库（ExecuteUpdate）；租户上下文 → SetTenantId 写入/恢复配对；权限聚合 → claims 写入 | ✅ |
| 状态变更 | 成员状态机（PendingInvite →Enabled 激活 / Disabled 拒绝）；租户状态机（Enabled / GracePeriod 允许 / Disabled 拒绝）；TokenVersion 递增失效 | ✅ |
| 边界处理 | 128 长度上限、参数化锁定阈值、IP 20 次窗口、宽限期 10 分钟、历史密码窗口 N=0 跳过 | ✅ |

## 五、潜在缺陷检查（用户要求第 4 条）

| 检查项 | 方法 | 结果 |
|---|---|---|
| 空指针引用 | 全部 null 入口（principal / user / token / claims 缺失）均有对应拒绝或抛异常用例；`?.` 链三态覆盖 | ✅ 未发现缺陷 |
| 数组越界 | 认证域无数组索引操作；列表操作均为 LINQ / FirstOrDefault 防御式 | ✅ 未发现缺陷 |
| 类型不匹配 | 混淆 ID 全部经 `TryDecode` 防御；强类型 DTO 绑定 | ✅ 未发现缺陷 |
| 资源泄漏 | EF Core 上下文全部 `await using`；SQLite 内存连接在测试类 `Dispose` 释放；缓存经 `ICacheService` 唯一入口无裸连接 | ✅ 未发现缺陷 |
| 敏感信息泄露 | 缓存键 SHA256 哈希化（无明文账号 / IP）；`QlxAuthOptions.ToString()` 掩码断言 | ✅ 未发现缺陷 |

**产品代码缺陷清单：0 项。** 测试过程中仅发现测试基建问题（桩注册键未含接口、InMemory 提供方不支持 ExecuteUpdate、SQLite 外键约束），均已修正，不涉及产品代码。
