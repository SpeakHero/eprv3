## 一、页面链路说明

### 1.1 导航入口

支撑功能 5 个中心页面统一挂载在租户管理布局（`TenantAdminLayout`）左侧导航的「支撑功能」分组下，入口路径如下：

| 页面 | 路由路径 | 路由名称 | 标题 |
|------|----------|----------|------|
| 审批中心 | `/manage/support/approvals` | `support-approvals` | 审批中心 |
| 信息中心 | `/manage/support/messages` | `support-messages` | 信息中心 |
| 后台任务中心 | `/manage/support/jobs` | `support-jobs` | 后台任务中心 |
| 文件中心 | `/manage/support/files` | `support-files` | 文件中心 |
| 打印模板 | `/manage/support/printing` | `support-printing` | 打印模板 |

所有支撑中心路由的 `meta.requiresTenantData = true`，由路由守卫统一校验租户上下文 Token，未登录自动跳转 `/login`。

### 1.2 页面跳转逻辑

```
工作台(/workbench) → 企业管理(/manage/*)
                       ├─ 企业管理分组（组织/成员/角色/模块）
                       └─ 支撑功能分组
                           ├─ 审批中心 ── 详情抽屉(ApprovalActionBar + Timeline)
                           ├─ 信息中心 ── 发送日志抽屉
                           ├─ 后台任务 ── 执行日志抽屉 / 触发任务弹窗
                           ├─ 文件中心 ── 预览(新窗口)
                           └─ 打印模板 ── 编辑弹窗 / 渲染预览弹窗
```

- 审批中心：待办列表 → 点击「处理」打开详情抽屉 → 通过 `ApprovalActionBar` 执行通过/驳回/加签/转办/催办/撤回；我发起的列表支持「撤回」。
- 信息中心：收件箱/已发送/订阅管理三 Tab；已发送支持查看渠道投递日志与人工重试。
- 后台任务：任务定义启停 / 执行历史过滤 / 点击查看执行日志 / 手动触发任务。
- 文件中心：文件列表 + 上传（复用 `FileUploader` 双模式）+ 回收站还原。
- 打印模板：模板 CRUD + 启停 + 渲染预览（输入变量 JSON → iframe 展示渲染 HTML）。

### 1.3 路由注册与守卫验证

- 构建通过：`vue-tsc` 类型检查 0 错误，`vite build` 产物正常输出 5 个支撑页面 chunk。
- 浏览器验证：5 条 `/manage/support/*` 路由均正确注册，未登录时被守卫重定向至 `/login`，公共演示页 `/dev/components` 正常渲染，控制台无错误。

### 3.2 接口契约对齐要点

- **JSON 枚举序列化为整数**：后端 `QlxJsonDefaults` 未注册 `JsonStringEnumConverter`，C# 枚举序列化为整数，前端 `types/support.ts` 使用整数 code 类型（如 `MessageStatusCode = 0|1|2|...`）。
- **Id 一律 string**：后端 `long` 属性经 Hashids 混淆，前端所有 Id 字段类型为 `string`。
- **统一响应**：`ApiResponse<T> { success, code, message, data }`，API 层统一解包 `data`。
- **审批状态转换**：后端整数状态 → 经 `support-approval-adapter.ts` 的 `convertInstance` 转为 `ApprovalActionBar` 组件期望的字符串状态。

## 四、模拟数据使用说明

### 4.1 API 层真实调用优先

`api/support.ts` 中所有函数均直接调用后端真实接口（经 `core/http.ts` 自动注入 Token、401 静默续期），**未内置 mock 兜底逻辑**。当后端接口不可达时，由 HTTP 客户端统一抛出错误，页面捕获后通过 `ElMessage.error` 提示。

### 4.2 文件上传服务

`FileCenterView` 向 `FileUploader` 注入 `realFileUploadService`（来自 `components/file/file-api.ts`），调用真实 `/api/support/files/upload` 端点。若未注入 service，`FileUploader` 回退到 `mockFileUploadService`（仅组件演示页使用）。

### 4.3 审批候选人清单

`ApprovalActionBar` 组件内通过 `service.listUsers()` 获取加签/转办候选人。当前 `realApprovalServiceAdapter.listUsers()` 返回空数组（后端租户成员查询接口尚未接入），加签/转办选人功能暂受限，待接入租户成员查询接口后补全。

### 4.4 后端未就绪接口的占位策略

阶段二后端 2A~2F 全部完成，前端对接的均为已实现接口。对于尚未部署或网络不可达的情况，页面展示空列表 + 错误提示，不阻断页面渲染。

## 五、待优化点汇总

| 优先级 | 项 | 说明 |
|--------|----|------|
| P0 | 审批加签/转办候选人 | `listUsers()` 返回空，需接入租户成员查询接口填充候选人选项 |
