## 四、缺陷修复记录（复测闭环）

| # | 缺陷 | 根因 | 修复与守护 |
|---|------|------|------------|
| 1 | 审批待办恒空 | 审批人 Id 以原始 long 落库，与 token `sub`（Hashids 混淆串）不一致 | `BasApprovalApproverSource` 注入 `IIdObfuscator` 统一 `Encode`；单测覆盖编码一致性 |
| 2 | 子公司级字典对租户管理员不可见 | `scope=null` 被当作「无 OrgId」过滤 | `QueryDictTypesAsync` 增 `unrestricted`；缓存键含范围标记；`EnsureVisibleAsync` 放行 |
| 3 | 人员「员工」类型缺组织/岗位必填 | 表单组件无条件下必填能力 | `FormField.requiredWhen` + `isFieldRequired` 纯函数 + 7 例单测 |
| 4 | 审批通过后供应商状态不生效 | `OutboxDispatcher` 以 `dynamic` 跨程序集调用 `ConsumeAsync`，消费者类 `internal` → 绑定降级 `object`（`RuntimeBinderException`） | 消费者改 `public` + 架构测试守护（模块程序集内消费者必须 public） |
