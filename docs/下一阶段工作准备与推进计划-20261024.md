### 4.2 每模块固定交付物（15 项，沿用开发推进计划）

csproj（仅引 Abstractions+BuildingBlocks）/ 独立 DbContext+表前缀 / 首次迁移 / Domain 实体 / DTO（Hashids 边界）/ Mapperly 映射 / Service（接口先下沉 Abstractions）/ Controller（零业务逻辑）/ 状态机与校验前置 / 事件发布订阅 / Abstractions 查询接口 / IModule Manifest（含菜单+权限点+任务+订阅事件）/ 单元测试 / Host 冒烟集成 / config/modules/<name>.json。

**叠加约束（相对阶段一的增量）**：
1. 业务编码一律 `IEncodingGenerator`（N-x），前端表单无编码输入框；
2. 单据编号一律 `IDocumentNumberGenerator`，前缀按约定（CG-/XS-/WL-/SP-/RY-/CW-/PJ-/HT-/XM-/ZL-）；
3. 审批接入只依赖 `IApprovalService`，条件分支用 condition-builder AST；
4. 导入导出/打印/附件直接复用阶段二组件，禁重造；
5. 缓存/职责边界/双层校验按 C-x/B-x/V-x 逐条过评审（E-1 检查点）；
6. 库存台账只由流水驱动、移动加权平均（第二波专项验收）。
