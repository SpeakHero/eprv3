# 模块需求详设：05 商品管理

> 对应《项目需求.md》4.5 ｜ 版本 v1.0 ｜ 2026-10-20
> 维护商品/物资主档案与库存价值台账，是采购、销售、物流、财务成本核算的共同数据源。分类与编码规则引用《01-基础信息中心.md》，出入库动作由《04-物流管理.md》作业驱动，成本核算对接《07-财务管理.md》。

## 2. 核心实体与字段明细

### 2.1 商品档案 item

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| item_id | bigint PK | 是 | 主键 |
| item_code | varchar(24) | 是 | 商品编码，全局唯一（分类码+流水码，发号服务发放） |
| item_name | varchar(128) | 是 | 商品名称 |
| category_id | bigint | 是 | 商品分类（引用基础中心，仅可选启用状态分类） |
| spec | varchar(128) | 否 | 规格型号 |
| barcode | varchar(32) | 否 | 条码，唯一（非空时） |
| unit_id | bigint | 是 | 主计量单位（分类带出默认单位组） |
| batch_enabled / expiry_enabled | bit | 是 | 是否启用批次/效期管理；启用后出入库必填批次 |
| tax_rate | decimal(5,4) | 是 | 默认税率（字典引用：13%/9%/6%/0 等） |
| ref_cost_price | decimal(18,4) | 否 | 参考成本价（权限可见） |
| guide_price | decimal(18,4) | 否 | 销售指导价 |
| image_file_id | bigint | 否 | 商品影像 |
| status | enum | 是 | ENABLED / DISABLED；被引用后禁止删除仅可停用 |

价格变更历史 item_price_log：log_id、item_id、field（ref_cost_price/guide_price）、old_value、new_value、approved_by、created_at。税率/单位变更同留痕。

### 2.2 库存台账 stock_balance（核心账）

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| balance_id | bigint PK | 是 | 主键 |
| item_id / warehouse_id | bigint | 是 | 维度键（唯一索引 item+warehouse） |
| qty_onhand | decimal(18,4) | 是 | 现存数量，≥0（出库校验保证不负） |
| avg_cost | decimal(18,4) | 是 | 移动加权平均单价 |
| amount | decimal(18,2) | 是 | 库存金额 = qty × avg_cost（金额按分位） |
| qty_locked | decimal(18,4) | 是 | 冻结量（盘点冻结/占用），可售量=qty_onhand-qty_locked |
| last_txn_at | datetime | 是 | 最近变动时间 |

批次台账 stock_batch：batch_id、item_id、warehouse_id、batch_no、produce_date、expiry_date、qty、avg_cost、amount。

### 2.3 出入库流水 stock_txn（只增不改）

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| txn_id | bigint PK | 是 | 主键 |
| txn_no | varchar(32) | 是 | 流水号（发号服务） |
| source_type | enum | 是 | 来源类型（采购入库/销售出库/调拨/盘盈/盘亏/期初/成本调整/领用/退货等） |
| source_doc_no | varchar(32) | 是 | 来源单据号（可反查） |
| item_id / warehouse_id / batch_no | - | 是 | 维度 |
| direction | enum | 是 | IN 入 / OUT 出 |
| qty | decimal(18,4) | 是 | 数量（正数） |
| unit_cost / amount | decimal | 是 | 单价/金额（入库按实际价，出库按当时 avg_cost） |
| balance_qty_after / balance_amount_after | decimal | 是 | 变动后结存（便于审计追溯） |
| operator_id / created_at | - | 是 | 经办人与时间 |

管控：流水表物理上只 INSERT，禁止 UPDATE/DELETE（数据库层约束），错账通过红字流水冲正。

### 2.4 期初建账批 opening_batch / 明细 opening_item

opening_batch：batch_id、batch_no、warehouse_id、status（草稿→待审批→已过账）、posted_at。
opening_item：id、batch_id、item_id、qty、unit_cost、amount、batch_no（启用批次商品）。

### 2.5 成本调整单 cost_adjust

主表：adj_id、adj_no（`SP-CB-…`）、reason_code（价格差错/盘盈盘亏联动/其他）、total_diff_amount、status。
明细：item_id、warehouse_id、old_avg_cost、new_avg_cost、diff_amount（=qty×(new-old)）。
管控：审批生效后重算台账 avg_cost/amount，并生成红字/蓝字流水各一条；同步财务成本调整凭证。

## 3. 业务规则与校验

| # | 规则 | 说明 |
|---|------|------|
| R1 | 编码唯一 | 商品编码全局唯一，按「分类码+流水码」发号；条码非空时唯一 |
| R2 | 引用保护 | 被任何业务单据/库存引用过的商品禁止删除，仅可停用；停用商品不可新增业务，库存可继续出库消化 |
| R3 | 关键字段审批 | 税率、计量单位、批次属性的变更需审批（单位变更仅允许同单位组内换算） |
| R4 | 移动加权平均 | 入库后重算：`avg_cost = (原金额+入金额)/(原数量+入数量)`；出库按当时 avg_cost 计成本；单价精度 4 位、金额 2 位 |
| R5 | 台账只读 | 库存台账仅由出入库流水驱动更新，禁止任何界面手工直接修改；所有变动可通过 balance_qty_after 逐笔反查 |
| R6 | 期初一次性 | 期初过账后 opening_batch 锁定，期初错误只能通过成本调整单/盘盈盘亏单修正 |
| R7 | 批次完整性 | 启用批次商品出入库必填批次号；启用效期商品必填效期，临期预警按参数天数计算 |
| R8 | 成本调整留痕 | 成本调整必须填写原因并经审批；调整后自动同步财务凭证，前后成本可对比 |
| R9 | 负库存拦截 | 出库类流水提交时校验 `qty ≤ qty_onhand - qty_locked`，不足阻断并返回缺口明细 |
| R10 | 计价一致性 | 财务成本科目取数仅允许来自本模块台账/流水，禁止业务模块自行计算成本金额 |

## 4. 审批流配置建议

| 单据 / 事件 | 触发条件 | 建议审批链 | 说明 |
|------------|---------|-----------|------|
| 商品新建 | 全部 | 基础数据管理员 → 采购/销售负责人会签（按需） | 可配置为管理员单级 |
| 关键字段变更（税率/单位/批次） | 全部 | 基础数据管理员 → 财务负责人 | 税率影响税务口径 |
| 期初过账 | 全部 | 仓库负责人 → 财务负责人 → 集团运营负责人 | 与财务期初核对一致方可过账 |
| 成本调整单 | 金额 ≤ 阈值 | 仓库/商品负责人 → 财务负责人 | — |
| 成本调整单 | 金额 > 阈值 | 上述 + 集团分管副总 | 阈值参数化 |
| 商品停用 | 有库存商品 | 商品负责人 → 集团运营负责人 | 需确认消化/清理方案 |

## 5. 权限点清单

**菜单**：商品管理 → 商品档案 / 期初建账 / 库存台账 / 出入库流水 / 成本调整 / 批次库存 / 商品报表。

**按钮**：新建、编辑、停用/启用、提交审批、期初录入/过账、成本调整发起、流水导出、台账导出、批次追溯、打印（商品条码标签）。

**数据权限**：商品档案租户级共享（全员只读引用、专岗维护）；库存台账按仓库所属组织继承权限；成本价字段（ref_cost_price、avg_cost、amount）默认仅财务、采购负责人、销售负责人可见。

**字段权限**：avg_cost / amount 对仓库作业人员隐藏（只见数量，参数可配）。

## 6. 与其他模块联动

| 触发事件 | 目标模块 | 数据流 |
|---------|---------|-------|
| 物流作业确认（入/出库） | 物流管理 → 本模块 | 写入流水并重算台账（R4） |
| 销售出库流水生成 | 财务管理 | 按出库成本金额生成销售成本凭证 |
| 盘盈盘亏/成本调整生效 | 财务管理 | 生成库存成本调整凭证 |
| 商品停用/关键字段变更 | 采购/销售 | 新单据引用校验与价格带出同步更新 |
| 库存量变化 | 物流管理 | 触发安全库存/积压/临期预警计算 |
| 期初过账 | 财务管理 | 期初库存金额与财务存货科目核对锁定 |
| 项目领用出库 | 项目管理 | 领用成本归集至项目材料科目 |

## 7. 期初与历史数据处理

| 事项 | 处理方式 |
|------|---------|
| 期初建账 | 上线前按仓库分批录入期初库存（数量×单价），启用批次商品逐批录入批次与效期 |
| 核对机制 | 期初过账前输出「仓库汇总表」与财务存货科目余额核对，差异归零后方可过账 |
| 过账锁定 | 过账后期初数据只读，生成期初流水（source_type=期初），后续修正走调整单 |
| 历史价格 | 历史采购/销售价格可作为参考基线导入 ref_cost_price / guide_price 或独立基线表 |
| 历史流水 | 历史出入库流水不补录；期初即系统流水的起点 |
