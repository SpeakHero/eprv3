# 模块需求详设：09 合同管理（扩展模块）

> 对应《项目需求.md》4.9 ｜ 版本 v1.0 ｜ 2026-10-20
> 统一管理采购、销售、劳务分包、设备租赁各类合同，实现「合同→订单→结算→收付款→票据」闭环。对方单位引用《01-基础信息中心.md》供应商/客户档案；执行数据来自《02/03/06/07/08/11》各模块回写。

---

## 1. 功能清单（页面级）

| # | 页面 | 类型 | 核心功能 |
|---|------|------|---------|
| 1 | 合同台账列表 | 列表页 | 按类型/状态/对方单位/到期区间筛选，临期合同标识 |
| 2 | 合同登记页 | 表单页 | 合同信息登记（类型、对方、金额、税率、期限、收付款条款、质保条款）、影像附件上传 |
| 3 | 合同评审审批页 | 审批页 | 评审意见逐节点登记（业务/财务/法务/管理层），非标条款高亮展示 |
| 4 | 合同详情 | 详情页（Tab） | 合同要素 / 补充协议 / 执行看板（下单/交付/开票/收付款）/ 质保与保证金 / 操作日志 |
| 5 | 合同变更（补充协议）页 | 表单页 | 变更类型（金额/期限/条款）、变更前后对比、与原合同关联 |
| 6 | 合同执行看板 | 看板页 | 按合同归集已下单、已交付/入库、已开票、已收付款金额与执行率，双向穿透 |
| 7 | 质保与保证金台账 | 列表页 | 质保金/履约保证金登记、到期提醒、释放申请与审批 |
| 8 | 合同到期预警看板 | 看板页 | 临近到期未履约、超付、超发预警清单 |
| 9 | 合同模板库 | 配置页 | 标准合同模板维护，模板合同可配置简化评审流程 |

## 2. 核心实体与字段明细

### 2.1 合同 contract（主表）

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| contract_id | bigint PK | 是 | 主键 |
| contract_no | varchar(32) | 是 | 合同编号，全局唯一（`HT-类型码-{yyyy}-{seq}`，如 HT-CG-2026-0001） |
| contract_type | enum | 是 | PURCHASE 采购/SALE 销售/LABOR 劳务分包/RENT 设备租赁/OTHER 其他 |
| counter_type / counter_id | enum+bigint | 是 | 对方单位类型（供应商/客户/劳务公司）与档案引用 |
| sign_date | date | 是 | 签订日期 |
| effect_date / expiry_date | date | 是 | 履行期限 |
| total_amount | decimal(18,2) | 是 | 合同金额（价税合计） |
| tax_rate | decimal(5,4) | 是 | 税率 |
| payment_terms | varchar(512) | 是 | 收付款条款（预付/进度/质保比例与节点） |
| warranty_terms | varchar(512) | 否 | 质保条款（比例、期限） |
| is_standard_tpl | bit | 是 | 是否标准模板合同（简化评审依据） |
| nonstandard_clauses | text | 否 | 非标条款摘要（评审高亮） |
| file_id | bigint | 是 | 合同影像（盖章扫描件） |
| org_id | bigint | 是 | 归属组织（签约主体公司） |
| status | enum | 是 | 草稿→评审中→已签订→履行中→已完成/已终止/已作废 |

执行归集（系统计算，只读）：ordered_amount（已下单）、delivered_amount（已交付/入库）、invoiced_amount（已开票）、paid_amount（已付）/received_amount（已收）。

### 2.2 补充协议 contract_amendment

amend_id、amend_no（`HT-BD-…`）、contract_id、amend_type（AMOUNT 金额/TERM 期限/CLAUSE 条款）、old_value/new_value（json 对比）、reason、file_id、status。
管控：累计变更金额超原合同 N%（参数，默认 10%）升级审批。

### 2.3 质保与保证金 warranty_deposit

wd_id、contract_id、wd_type（WARRANTY 质保金/PERFORMANCE 履约保证金）、amount、due_date（到期日）、release_status（未到期/待释放审批/已释放/已扣罚）、release_apply_no（释放申请单号）、验收结论（释放审批引用）。

### 2.4 合同模板 contract_template

tpl_id、tpl_name、contract_type、version、content_file_id、review_flow_id（简化评审链绑定）、status。

## 3. 业务规则与校验

| # | 规则 | 说明 |
|---|------|------|
| R1 | 无合同不业务 | 采购订单、销售订单、劳务结算、设备起租原则上必须关联有效合同（或框架协议）；未关联的走特批通道并限期 N 天补登合同，逾期单据冻结 |
| R2 | 编号唯一 | 合同编号全局唯一，按类型码分段发号；作废不回收 |
| R3 | 分级评审 | 评审链按「合同类型×金额区间」配置（流程配置中心）；标准模板合同可简化（业务+财务两级） |
| R4 | 非标提示 | 非常规付款条款、违约责任等非标条款在评审页强制高亮，评审人必须逐项确认 |
| R5 | 变更管控 | 补充协议审批生效后更新合同要素并保留前后版本对比；累计变更超阈值升级 |
| R6 | 超付拦截 | 付款累计超合同金额（或超付款条款节点比例）时，付款申请阻断并提示 |
| R7 | 超发拦截 | 交付/下单累计超合同金额时预警，超 N%（参数）阻断需先变更合同 |
| R8 | 到期预警 | 距 expiry_date N 天（参数，默认 60/30/7 三级）未履约完毕自动预警至业务负责人 |
| R9 | 质保释放 | 质保金/保证金到期自动提醒；释放必须附验收结论并分级审批，留痕可查 |
| R10 | 双向穿透 | 合同↔订单↔出入库↔发票↔收付款全链路双向穿透查询（与 4.12.5 追溯链一致） |

## 4. 审批流配置建议

| 单据 / 事件 | 触发条件 | 建议审批链 | 说明 |
|------------|---------|-----------|------|
| 合同评审（标准模板） | 金额 ≤ 阈值D | 业务负责人 → 财务负责人 | 阈值参数化 |
| 合同评审（标准模板） | 金额 > 阈值D | 业务 → 财务 → 法务/风控 → 子公司总经理 | — |
| 合同评审（非标） | 全部 | 业务 → 财务 → 法务/风控 → 子公司总经理 → 集团分管副总 | 含非标条款强制集团节点 |
| 补充协议 | 变更 ≤ N% | 业务负责人 → 财务负责人 | — |
| 补充协议 | 累计变更 > N% | 同原合同评审链 | R5 |
| 合同终止/作废 | 全部 | 业务负责人 → 法务/风控 → 子公司总经理 | 须无在途业务或说明处置方案 |
| 质保/保证金释放 | 全部 | 项目经理/业务负责人 → 财务负责人 | 附验收结论 |

## 5. 权限点清单

**菜单**：合同管理 → 合同台账 / 合同登记 / 补充协议 / 执行看板 / 质保保证金 / 到期预警 / 模板库。

**按钮**：登记、编辑（草稿）、提交评审、签订登记、变更发起、终止/作废、影像上传/查看、释放申请、穿透查询、导出、打印。

**数据权限**：业务人员本公司本部门合同；法务/风控与集团角色全量；项目经理可见本项目关联合同。

**字段权限**：合同金额对非业务相关角色可配置隐藏（参数）。

## 6. 与其他模块联动

| 触发事件 | 目标模块 | 数据流 |
|---------|---------|-------|
| 订单/结算/起租关联合同 | 采购/销售/人员/设备模块 | 执行归集回写（下单/交付/开票/收付款） |
| 超付/超发拦截触发 | 财务管理 | 付款申请阻断提示联动 |
| 合同关联项目 | 项目管理 | 项目合同额、回款条款同步项目档案 |
| 质保金到期 | 财务管理 | 应付质保金释放付款申请依据 |
| 合同到期/异常预警 | 通知中心 | 三级预警推送至负责人 |
| 销项/进项发票关联订单 | 票据管理 | 已开票金额归集至合同执行看板 |

## 7. 期初与历史数据处理

| 事项 | 处理方式 |
|------|---------|
| 在履行合同 | 上线前有效合同全量登记（含已执行金额归集期初值），审批后置「履行中」 |
| 历史合同 | 已履行完毕合同登记要素与影像备查（不挂执行数据），状态「已完成」 |
| 补充协议 | 在履行合同的历史补充协议随主合同一并登记 |
| 质保挂账 | 未到期质保金/保证金期初登记，与财务应付/应收质保余额核对一致 |
