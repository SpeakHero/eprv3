# 模块需求详设：11 设备与租赁管理（扩展模块）

> 对应《项目需求.md》4.11 ｜ 版本 v1.0 ｜ 2026-10-20
> 承接贸易板块工程设备租赁业务，管理自有设备资产台账与租赁全流程，实现单机核算。租赁合同依据《09-合同管理.md》，折旧与收租联动《07-财务管理.md》，承租项目成本归集《10-项目管理.md》。

---

## 1. 功能清单（页面级）

| # | 页面 | 类型 | 核心功能 |
|---|------|------|---------|
| 1 | 设备台账列表 | 列表页 | 按状态（在库/在租/维修/停用/报废）/所属组织筛选，技术状态标识 |
| 2 | 设备档案表单 | 表单页 | 设备登记（资产编号、名称规格、购置日期与原值、所属组织）、影像与技术资料附件 |
| 3 | 设备详情 | 详情页（Tab） | 档案 / 租赁记录 / 维修记录 / 保养计划 / 单机核算 / 状态流转日志 |
| 4 | 起租登记页 | 表单页 | 关联租赁合同、承租方/项目、起租日、计费标准（日/月/台班） |
| 5 | 停租与退租登记页 | 表单页 | 停租日、退租验收记录（损坏情况、责任界定）、退租确认 |
| 6 | 租金结算单 | 表单页 | 按约定周期自动生成结算单（起租日→结算日×计费标准），转应收 |
| 7 | 维修申请 / 记录页 | 表单页 | 维修申请、送修登记、维修费用与明细、修复验收 |

| 9 | 单机核算看板 | 看板页 | 单机收入（租金）vs 成本（折旧/维修/人工分摊），盈利率排名 |

## 2. 核心实体与字段明细

### 2.1 设备档案 equipment

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| equip_id | bigint PK | 是 | 主键 |
| asset_code | varchar(20) | 是 | 资产编号，全局唯一（`SB-{yyyy}-{seq}`），与财务固定资产卡片号映射 |
| equip_name / spec | varchar(128) | 是 | 名称与规格型号 |
| purchase_date | date | 是 | 购置日期 |
| original_value | decimal(18,2) | 是 | 原值 |
| current_value | decimal(18,2) | 是 | 净值（折旧后，财务同步） |
| tech_status | enum | 是 | IDLE 在库/RENTED 在租/REPAIR 维修/STOP 停用/SCRAP 报废；流转留痕（R2） |
| org_id | bigint | 是 | 所属组织（公司） |
| file_ids | json | 否 | 影像与技术资料附件 |

状态流转日志 equip_status_log：log_id、equip_id、from_status、to_status、ref_doc_no（来源单据）、operator_id、created_at。

### 2.2 租赁单 equip_rent

rent_id、rent_no（`ZL-ZL-{orgCode}-{yyyyMM}-{seq}`）、equip_id、contract_id（关联租赁合同）、renter_type（CUSTOMER 客户/PROJECT 项目）、renter_id、start_date（起租日）、billing_standard（计费标准：日/月/台班+单价）、stop_date、status（在租→已停租→已退租结算）。
退租验收 return_check：check_id、rent_id、check_date、check_result（完好/损坏）、damage_desc、repair_charge（损坏赔偿金额）、file_id、operator_id。

### 2.3 租金结算单 rent_settle

settle_id、settle_no（`ZL-JS-…`）、rent_id、period_start/period_end、billing_qty（天数/月数/台班数）、unit_price、settle_amount、status（待结算→已结算→已开票→已收款）。
管控：按合同约定周期自动生成（定时任务），生成即转财务应收（R4）。

### 2.4 维修单 equip_repair

repair_id、repair_no（`ZL-WX-…`）、equip_id、apply_date、fault_desc、repair_org（维修单位/自修）、start_date/finish_date、total_cost、parts_detail（json 配件明细）、accept_result、status。
管控：维修期间设备置 REPAIR 禁止出租；费用归集单机（R6）。

### 2.5 保养计划 maintain_plan / 记录 maintain_record

plan：plan_id、equip_id、plan_type（HOUR 台班/CYCLE 周期）、threshold（台班数/天数）、last_maintain_at、next_due、status。
record：record_id、plan_id、maintain_date、content、cost、operator_id。
管控：到期前 N 天提醒；超期未保养设备禁止发起新起租（R5）。

### 2.6 单机核算视图 equip_pnl（系统计算）

收入：rent_settle 累计。成本：折旧（财务月度折旧同步）、维修费、保养费、人工分摊（按配置比例）。输出单机毛利与利用率（在租天数/可用天数）。

## 3. 业务规则与校验

| # | 规则 | 说明 |
|---|------|------|
| R1 | 资产联动 | 设备登记同步财务固定资产卡片；折旧按月从财务取数，本模块不自行计提 |
| R2 | 状态机管控 | 状态流转必须由业务单据驱动（起租→RENTED、维修申请→REPAIR、退租→IDLE 等），禁止直接改状态；全部流转留痕 |
| R3 | 在租唯一 | 同一设备同一期间仅允许一张有效在租单；起租校验冲突阻断 |
| R4 | 退租必验 | 退租必须附验收记录（含影像）；损坏需界定责任并登记赔偿，赔偿金额并入结算单 |
| R5 | 超保禁租 | 保养超期设备起租阻断，提示先完成保养登记 |
| R6 | 单机归集 | 维修、保养、折旧费用全部按 asset_code 归集，禁止分摊池手工调整 |
| R7 | 租金自动结算 | 按合同周期自动生成结算单，金额=计费量×单价±赔偿/优惠调整（调整需审批）；结算单生效即转应收 |
| R8 | 逾期预警 | 租金应收逾期联动财务账龄预警；承租方为客户时影响其信用占用 |
| R9 | 报废审批 | 报废需技术鉴定结论+分级审批；报废后同步财务固定资产清理 |
| R10 | 内部租赁 | 承租方为本集团项目（renter_type=PROJECT）时，结算金额归集项目机械成本，同时计入单机收入（内部结算口径） |

## 4. 审批流配置建议

| 单据 / 事件 | 触发条件 | 建议审批链 | 说明 |
|------------|---------|-----------|------|
| 设备登记/原值变更 | 全部 | 设备管理负责人 → 财务负责人 | 固定资产核对 |
| 起租登记 | 全部 | 设备管理负责人 | 金额 > 阈值F 加签子公司总经理 |
| 退租验收（含赔偿） | 有赔偿金额 | 设备管理负责人 → 业务负责人 → 财务负责人 | 无赔偿可单级 |
| 租金调整（减免） | 全部 | 业务负责人 → 财务负责人 → 子公司总经理 | R7 |
| 维修申请 | ≤ 阈值G | 设备管理负责人 | > 阈值G 加签子公司分管 |
| 报废申请 | 全部 | 设备管理负责人 → 财务负责人 → 集团分管副总 | 附技术鉴定 |

## 5. 权限点清单

**菜单**：设备与租赁 → 设备台账 / 起租管理 / 退租管理 / 租金结算 / 维修保养 / 单机核算 / 设备报表。

**按钮**：设备登记/编辑、起租/停租/退租登记、验收登记、结算单生成/调整、维修申请/记录、保养计划维护/执行登记、报废申请、看板导出。

**数据权限**：设备管理岗可见全公司设备；项目角色可见本项目承租设备；集团角色全量。单机成本（折旧/维修）对非财务与设备管理角色隐藏（参数可配）。

## 6. 与其他模块联动

| 触发事件 | 目标模块 | 数据流 |
|---------|---------|-------|
| 设备登记/折旧/报废 | 财务管理 | 固定资产卡片同步；月度折旧取数；报废清理凭证 |
| 租金结算单生效 | 财务管理 | 生成应收（客户）/内部结算（项目）与收入凭证 |
| 租金开票 | 票据管理 | 开票申请关联结算单，回写已开票状态 |
| 承租方为项目 | 项目管理 | 结算金额归集项目机械成本（R10） |
| 租赁合同关联 | 合同管理 | 起租/结算数据归集合同执行看板 |
| 客户承租逾期 | 销售管理 | 计入客户信用占用与账龄 |

## 7. 期初与历史数据处理

| 事项 | 处理方式 |
|------|---------|
| 设备期初 | 自有设备全量登记（原值、已提折旧、净值与财务固定资产核对一致），状态按上线日实际（在租设备同步补起租登记） |
| 在租业务期初 | 未到期租赁单补录（起租日、计费标准、合同关联），下一结算周期起自动生成结算单 |
| 维修保养历史 | 近 12 个月维修记录可补录作为单机成本基线；保养计划按期初台班/日期重算 next_due |
| 历史结算 | 历史租金结算数据不迁移；期初应收租金与财务期初应收一致 |
