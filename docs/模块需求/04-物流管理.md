# 模块需求详设：04 物流管理

> 对应《项目需求.md》4.4 ｜ 版本 v1.0 ｜ 2026-10-20
> 承载仓储实物「收、发、存、转、配」作业管理。库存数据本体在《05-商品管理.md》（本模块只驱动不持账），来源单据来自《02-采购管理.md》《03-销售管理.md》，跨组织调拨涉及架构规格的分级授权。

---

## 1. 功能清单（页面级）

| # | 页面 | 类型 | 核心功能 |
|---|------|------|---------|
| 1 | 仓库档案 | 列表+表单 | 仓库/库区/库位三级档案维护，类型（自有/租赁/项目临时仓），所属组织 |
| 2 | 入库作业工作台 | 作业页 | 待入库任务池（四类来源）、清点录入、上架库位登记、作业完成确认 |
| 3 | 出库作业工作台 | 作业页 | 待出库任务池、拣货单打印、复核校验、交接登记 |
| 4 | 物资调拨单列表 / 表单 | 列表+表单 | 调拨申请、调出方发货登记、在途跟踪看板、调入方收货确认 |
| 5 | 配送管理页 | 列表+表单 | 配送单（关联出库）、车辆/司机登记、路线登记、客户/项目签收与影像上传 |
| 6 | 签收差异处理页 | 处理页 | 短少/破损差异登记、责任界定、转异常流程 |
| 7 | 库存盘点计划页 | 列表+表单 | 盘点计划（按仓库/品类/周期）、盘点任务下发 |
| 8 | 盘点录入页 | 作业页 | 初盘/复盘数量录入（支持移动端扫码）、差异自动计算 |
| 9 | 盘盈盘亏单 | 表单+审批页 | 差异原因、处理结论（调整账面/追责）、审批后调整 |
| 10 | 库存预警看板 | 看板页 | 安全库存预警、库龄/积压预警、临期批次预警，一键生成补货/调拨建议 |
| 11 | 在途库存台账 | 查询页 | 调拨在途明细、超期未确认标红预警 |

## 2. 核心实体与字段明细

### 2.1 仓库 warehouse / 库区 zone / 库位 location

warehouse：warehouse_id、warehouse_code（唯一，`WH-流水`）、warehouse_name、wh_type（OWN 自有/RENT 租赁/TEMP 项目临时仓）、org_id（所属组织，可为公司或项目）、address、keeper_id（仓管员）、status。
zone：zone_id、warehouse_id、zone_code、zone_name。
location：location_id、zone_id、location_code（仓库内唯一）、barcode、status。
管控：停用仓库前置——库存数量全部为 0 且无未完成作业单。

### 2.2 入库作业单 stock_in_task

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| task_id | bigint PK | 是 | 主键 |
| task_no | varchar(32) | 是 | `WL-RK-{orgCode}-{yyyyMM}-{seq}` |
| source_type | enum | 是 | PURCHASE 采购 / SALE_RETURN 销售退货 / TRANSFER 调拨 / GAIN 盘盈 |
| source_doc_no | varchar(32) | 是 | 来源单据号（禁止无单入库，R1） |
| warehouse_id | bigint | 是 | 入库仓库 |
| status | enum | 是 | 待作业→作业中→已完成/已取消 |

明细：item_id、expect_qty（来源量）、count_qty（清点数）、location_id（上架库位）、batch_no（启用批次商品必填）、confirm_qty（确认入帐量）。
管控：confirm_qty 提交后由商品管理写入库存台账，本单不直接改库存。

### 2.3 出库作业单 stock_out_task

主表：task_id、task_no（`WL-CK-…`）、source_type（SALE 销售/PURCHASE_RETURN 采购退货/TRANSFER 调拨/LOSS 盘亏/USE 领用）、source_doc_no、warehouse_id、picker_id、checker_id、handover_to（交接人/司机）、status。
明细：item_id、apply_qty、pick_qty、check_qty（复核量，=pick_qty 方可交接）、batch_no（按效期先进先出建议）、location_id。

### 2.4 物资调拨单 stock_transfer（主表）

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| transfer_id | bigint PK | 是 | 主键 |
| transfer_no | varchar(32) | 是 | `WL-DB-{orgCode}-{yyyyMM}-{seq}` |
| from_wh_id / to_wh_id | bigint | 是 | 调出/调入仓库（校验不同） |
| from_org_id / to_org_id | bigint | 是 | 调出/调入组织；跨公司判定依据 |
| ship_date / expect_arrive | date | 否/是 | 发货日期 / 预计到达 |
| in_transit_days | int | 是 | 在途天数（系统计算） |
| status | enum | 是 | 待审批→已生效→调出已发货（在途）→调入已收货（完成）/已作废 |

明细：item_id、qty、ship_qty、receive_qty、diff_qty（差异=ship-receive）、diff_note。

### 2.5 配送单 delivery_note

主表：dn_id、dn_no（`WL-PS-…`）、source_doc_no（销售出库单等）、vehicle_no、driver_name/phone、route、ship_date、sign_status、sign_date、sign_file_id（签收影像）、status。
管控：签收完成后回写来源单据签收状态；差异转签收差异处理页。

### 2.6 盘点计划 stock_take_plan / 盘点单 stock_take

plan：plan_id、plan_no、warehouse_id、scope_type（全仓/品类/库位）、scope_value、plan_date、type（明盘/盲盘）、status。
stock_take：take_id、take_no（`WL-PD-…`）、plan_id、round（FIRST 初盘/SECOND 复盘）、status。
明细：item_id、batch_no、book_qty（账面，系统快照）、actual_qty（实盘录入）、diff_qty（自动计算）、diff_reason。
管控：盘点任务生成即冻结范围内库存异动（出入库阻断提示），盘点完成后解冻。

### 2.7 盘盈盘亏单 inv_adjust_doc

adj_id、adj_no（`WL-PYK-…`）、take_id（来源盘点单）、type（GAIN 盘盈/LOSS 盘亏）、reason、total_amount（按移动加权价估算）、status。审批生效后由商品管理调整库存台账并同步财务成本凭证。

## 3. 业务规则与校验

| # | 规则 | 说明 |
|---|------|------|
| R1 | 无单禁入 | 所有入库必须挂来源单据；来源单据不存在或状态非法时阻断 |
| R2 | 禁止负库存 | 出库复核提交时校验可用库存，不足即阻断并提示缺口量 |
| R3 | 先进先出 | 启用批次/效期商品按批次效期 FEFO 排序建议拣货，人工跳批需填原因 |
| R4 | 大额出库审批 | 出库单金额超阈值（参数）需仓库负责人+部门负责人审批后放行 |
| R5 | 跨公司调拨 | 调出/调入组织属不同子公司时，审批链自动升级至集团；跨公司调拨同步生成内部结算依据（财务） |
| R6 | 在途预警 | 在途天数 > N 天（参数，默认 7）未确认收货，自动预警调出/调入双方仓管与负责人 |
| R7 | 在途独立台账 | 调出确认发货即扣调出仓库存、记在途库存；调入确认后加调入仓库存、消在途；在途不参与可售 |
| R8 | 盘点冻结 | 盘点范围内库存异动阻断；盘盈盘亏必须审批后方可调整账面，禁止盘点录入直接改账 |
| R9 | 签收联动 | 配送签收完成自动推进来源订单状态；签收差异登记后转入异常处理并通知业务负责人 |
| R10 | 预警闭环 | 安全库存/积压/临期预警生成后推送通知中心，处理动作（补货/调拨/促销建议）需回填处理结果 |

## 4. 审批流配置建议

| 单据 / 事件 | 触发条件 | 建议审批链 | 说明 |
|------------|---------|-----------|------|
| 大额出库 | 金额 > 阈值 | 仓库负责人 → 部门负责人 | 阈值参数化 |
| 物资调拨（仓间/项目间） | 同一子公司内 | 调出仓库负责人 → 调入仓库负责人 | — |
| 物资调拨（跨公司） | 全部 | 调出方负责人 → 调入方负责人 → 集团运营负责人 | R5 |
| 盘盈盘亏单 | 全部 | 仓库负责人 → 财务负责人 | 金额超阈值加签集团分管 |
| 盘点差异率超限 | 差异率 > 阈值 | 集团运营负责人专项复核 | 触发复盘任务 |
| 仓库停用 | 全部 | 仓库负责人 → 集团运营负责人 | 前置校验通过方可提交 |

## 5. 权限点清单

**菜单**：物流管理 → 仓库档案 / 入库作业 / 出库作业 / 物资调拨 / 配送管理 / 库存盘点 / 盘盈盘亏 / 库存预警 / 在途台账。

**按钮**：仓库维护、作业接单、清点录入、上架确认、拣货、复核、交接、调拨发起/发货/收货、配送登记、签收登记、差异处理、盘点计划/录入/差异提交、导出、打印（拣货单/盘点表）。

**数据权限**：仓管员仅本仓作业单；仓库负责人本仓全量；子公司运营可见本公司全部仓库；集团角色全量。项目临时仓数据随项目权限。

## 6. 与其他模块联动

| 触发事件 | 目标模块 | 数据流 |
|---------|---------|-------|
| 采购入库单验收合格 / 销售出库单批准 | 采购/销售 → 本模块 | 自动生成入库/出库作业任务 |
| 作业完成（confirm_qty 提交） | 商品管理 | 写入库存台账与出入库流水 |
| 盘盈盘亏审批生效 | 商品管理 / 财务管理 | 调整库存台账；生成库存成本调整凭证 |
| 跨公司调拨完成 | 财务管理 | 生成内部结算应收应付依据 |
| 安全库存预警 | 采购管理 | 一键生成补货采购申请（source=STOCK_ALERT） |
| 积压/临期预警 | 销售管理 | 生成促销/去化建议任务 |
| 配送签收完成/差异 | 销售管理 | 回写出库单签收状态；差异转销售异常处理 |
| 项目临时仓出入库 | 项目管理 | 领用出库自动归集项目材料成本 |

## 7. 期初与历史数据处理

| 事项 | 处理方式 |
|------|---------|
| 仓库档案期初 | 上线前批量导入仓库/库区/库位档案，绑定所属组织 |
| 期初库存 | 由《05-商品管理.md》期初建账统一承接，本模块不单独录库存 |
| 在途调拨 | 上线日在途的调拨业务，以「期初在途单」登记（调出已发、调入未收），入库按正常收货流程完成 |
| 历史台账 | 历史出入库流水不补录；期初建账后系统流水自上线日起连续记录 |
