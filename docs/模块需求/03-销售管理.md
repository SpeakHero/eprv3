## 2. 核心实体与字段明细

### 2.1 销售报价 sales_quote（主表）

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| quote_id | bigint PK | 是 | 主键 |
| quote_no | varchar(32) | 是 | `XS-BJ-{orgCode}-{yyyyMM}-{seq}` |
| customer_id | bigint | 是 | 引用客户档案（status=ACTIVE） |
| quote_date / valid_until | date | 是 | 报价日期 / 有效期截止；超期自动失效 |
| total_amount / tax_amount / total_with_tax | decimal | 是 | 明细汇总（价税分离） |
| version | int | 是 | 报价版本，重报自动 +1，历史版本可查 |
| status | enum | 是 | 草稿→待审批→审批中→已生效/已驳回→已转化/已失效 |

明细 sales_quote_item：item_id、qty、quote_price、tax_rate、amount、cost_price（参考成本，系统带出，权限可见）、guide_price（指导价，带出）、discount_rate（对指导价下浮率，自动计算）。

### 2.2 销售订单 sales_order（主表）

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| so_id | bigint PK | 是 | 主键 |
| so_no | varchar(32) | 是 | `XS-SO-{orgCode}-{yyyyMM}-{seq}` |
| customer_id | bigint | 是 | 下单即校验信用（R2） |
| quote_id / contract_id | bigint | 否/条件必填 | 来源报价 / 关联合同 |
| project_id | bigint | 否 | 关联项目（材料供应类业务） |
| total_with_tax | decimal(18,2) | 是 | 价税合计（明细汇总） |
| gross_margin_est | decimal(18,2) | 是 | 预估毛利（金额-成本，系统计算） |
| payment_terms | varchar(256) | 是 | 回款条款（预收%/发货%/账期%） |
| delivery_plan | json | 否 | 分批交付计划（日期+数量） |
| version | int | 是 | 变更版本；变更影响信用占用的重新校验 |
| status | enum | 是 | 通用状态机 + 执行态：部分出库/已出库/已关闭 |

明细 sales_order_item：item_id、qty、price、tax_rate、amount_with_tax、shipped_qty（已出累计）、invoiced_qty、returned_qty。

### 2.3 销售出库单 sales_delivery

主表：delivery_id、delivery_no（`XS-CK-…`）、so_id、warehouse_id、ship_date、sign_status（待签收/已签收/差异签收）、sign_date、sign_file_id（签收影像）、status。
明细：item_id、apply_qty（申请发货）、pick_qty（拣货）、ship_qty（实际出库）、batch_no、sign_qty（签收量）、diff_type（NONE/SHORT/DAMAGE）、diff_note。

### 2.4 销售退货单 sales_return

主表：return_id、return_no（`XS-TH-…`）、so_id、delivery_id（原出库单）、customer_id、return_type（REFUND 退款 / EXCHANGE 换货）、qc_result、status。
明细：item_id、qty（≤ 已出未退量）、price、amount。

### 2.5 销售对账单 sales_statement

主表：stmt_id、stmt_no（`XS-DZ-…`）、customer_id、period_start/end、ship_amount、return_amount、received_amount、balance（应收余额）、confirm_mode（线上确认/影像回传）、confirm_file_id、confirm_date、status。
明细 stmt_line：delivery_no、return_no、item_id、qty、amount、invoice_no。

### 2.6 回款计划与核销 receipt_plan / receipt_writeoff

receipt_plan：plan_id、so_id、phase（PRE 预收/DELIVERY 发货款/PERIOD 账期款）、plan_amount、plan_date、status（未到期/部分核销/已核销/逾期）。
receipt_writeoff：writeoff_id、receipt_id（财务到账登记）、so_id/plan_id、amount、writeoff_date、operator_id。支持一笔到账拆分核销多订单多期计划。

## 3. 业务规则与校验

| # | 规则 | 说明 |
|---|------|------|
| R1 | 定价管控 | 报价低于参考成本价，或对指导价下浮超 N%（参数，默认 15%）→ 强制升级审批并必填定价说明 |
| R2 | 信用校验 | 下单/发货时校验 `credit_used + 本单未回款金额 ≤ credit_limit`；超额冻结提交，提示走特批（特批链含财务与集团分管） |
| R3 | 负毛利拦截 | 订单预估毛利为负 → 强制集团级审批 |
| R4 | 出库限量 | 累计出库 ≤ 订单量；分批发货按计划执行，超计划需订单变更 |
| R5 | 库存校验 | 发货申请校验库存可用量，不足时提示缺口并可一键转调拨/采购建议 |
| R6 | 出库即应收 | 出库单签收确认后生成应收账款与回款计划（按条款拆分），库存同步扣减 |
| R7 | 退货核对 | 退货必须引用原出库单；质检合格入库后联动应收冲减与库存增加；退款走财务付款流程 |
| R8 | 逾期管控 | 回款计划逾期自动预警至业务员与负责人；逾期超 N 天（参数，默认 30）自动下调客户信用等级一级并触发订单复检 |
| R9 | 对账确认 | 对账单经客户确认（线上确认或盖章影像回传）后方可作为应收核销依据 |
| R10 | 报价失效 | 报价超 valid_until 自动失效，不可转化订单；转化后报价置「已转化」只读 |

## 4. 审批流配置建议

| 单据 / 事件 | 触发条件 | 建议审批链 | 说明 |
|------------|---------|-----------|------|
| 销售报价 | 正常价格 | 销售负责人 | — |
| 销售报价 | 低于成本或下浮超限 | 销售负责人 → 财务负责人 → 子公司总经理 | R1 触发 |
| 销售订单 | 信用内、毛利为正 | 销售负责人 | 金额 > 阈值B（参数）加签子公司总经理 |
| 销售订单 | 信用超额特批 | 销售负责人 → 财务负责人 → 集团分管副总 | R2 触发 |
| 销售订单 | 负毛利 | 销售负责人 → 子公司总经理 → 集团分管副总 | R3 触发 |
| 销售出库（信用超额客户） | 全部 | 财务负责人特批放行 | 常规出库由仓库按单执行，无需审批 |
| 销售退货 | 全部 | 销售负责人 → 仓库负责人（质检）→ 财务负责人（退款） | 换货免财务节点 |
| 坏账/减免核销 | 全部 | 财务负责人 → 集团总经理 | 关联 4.7 往来账款 |

## 5. 权限点清单

**菜单**：销售管理 → 销售报价 / 销售订单 / 发货与出库 / 销售退货 / 销售对账 / 回款管理 / 销售报表。

**按钮**：新建、编辑、提交审批、报价重报（新版本）、订单变更/关闭、发货申请、签收登记、差异登记、退货发起、对账生成/确认、到账认领、核销/拆分核销、导出、打印、查看成本与毛利。

**数据权限**：业务员仅本人单据；销售负责人本公司全部；集团角色全量；客户相关数据（回款、对账）财务角色按公司可见。

**字段权限**：cost_price、gross_margin_est 默认仅销售负责人及以上、财务可见；业务员不可见成本（参数可配）。

## 6. 与其他模块联动

| 触发事件 | 目标模块 | 数据流 |
|---------|---------|-------|
| 发货申请批准 | 物流管理 | 生成出库作业任务（拣货→复核→交接） |
| 出库签收确认 | 商品管理 / 财务管理 | 库存扣减；生成应收凭证与回款计划 |
| 退货质检入库 | 商品管理 / 财务管理 | 库存增加；应收冲减凭证 |
| 开票申请（关联订单/对账单） | 票据管理 | 销项开票登记回写 invoiced_qty；开票金额 ≤ 可开票余额 |
| 到账登记 | 财务管理 | 待认领款项池 → 本模块认领核销 → 应收核销回写 |
| 客户信用下调（R8/基础中心） | 基础信息中心 | 更新 credit_grade；触发在售订单复检任务 |
| 项目类订单出库 | 项目管理 | 归集项目收入，产值/收支台账更新 |
| 订单关联合同 | 合同管理 | 归集合同已交付/已开票/已回款金额 |

## 7. 期初与历史数据处理

| 事项 | 处理方式 |
|------|---------|
| 在途订单 | 未执行完销售订单按期初模板导入（含已出量、已开票、已回款），审批生效，期初号段独立 |
| 期初应收 | 按客户汇总期初应收余额导入，与财务期初一致；明细可挂「期初余额单」不逐笔还原 |
| 回款计划重建 | 在途订单按原条款重建回款计划，逾期部分直接进逾期台账 |
| 历史单据 | 已完成历史业务不补录；历史销售价格可导入作为定价参考基线 |
