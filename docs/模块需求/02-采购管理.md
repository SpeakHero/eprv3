## 1. 功能清单（页面级）

| # | 页面 | 类型 | 核心功能 |
|---|------|------|---------|
| 1 | 采购申请列表 | 列表页 | 状态/组织/日期筛选，补货来源标识，批量提交审批 |
| 2 | 采购申请单 | 表单页 | 明细批量录入（商品、数量、期望单价、期望交期、用途）；支持从库存预警带入、从项目预算余量带入 |
| 3 | 询比价单 | 表单+对比页 | 关联申请发起询价，多供应商报价登记，自动生成比价表（历史均价参考线） |
| 4 | 采购订单列表 / 详情 | 列表+详情 | 状态跟踪（生效/部分入库/已入库/已关闭）、执行进度条、关联单据跳转 |
| 5 | 采购订单单 | 表单页 | 由申请/比价结果生成或手工创建；价税分离编辑；交付批次计划；订单变更入口 |
| 6 | 到货登记页 | 表单页 | 按订单登记到货批次，打印到货通知 |
| 7 | 采购入库单 | 表单页 | 数量清点、质量验收结论、差异登记（短交/超交/破损）、库位上架确认 |
| 8 | 采购退货单 | 表单页 | 基于入库单选择退货明细，退货原因、责任方、退款方式 |
| 9 | 采购对账单 | 表单+核对页 | 按供应商/账期自动汇总「订单-入库-发票」，差异逐笔标红，说明登记 |
| 10 | 采购结算 / 付款衔接页 | 详情页 | 对账单转应付、发起付款申请、分期（预付/进度/质保）台账 |
| 11 | 采购台账与报表 | 报表页 | 采购执行表、供应商供货分析、价格趋势、订单准时交付率 |

## 2. 核心实体与字段明细

### 2.1 采购申请 purchase_request（主表）

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| pr_id | bigint PK | 是 | 主键 |
| pr_no | varchar(32) | 是 | 单据号 `CG-SQ-{orgCode}-{yyyyMM}-{seq}` |
| org_id / dept_id / project_id | bigint | 是 | 申请组织/部门/项目（关联项目时占用预算） |
| applicant_id | bigint | 是 | 申请人 |
| source | enum | 是 | MANUAL 手工 / STOCK_ALERT 库存预警 / PLAN 计划 |
| total_est_amount | decimal(18,2) | 是 | 预估总额（明细汇总，只读） |
| status | enum | 是 | 通用状态机：草稿→待审批→审批中→已生效/已驳回→执行中→已完成/已作废 |
| remark | varchar(512) | 否 | 用途说明 |

明细 purchase_request_item：item_id、item_name（快照）、unit_id、qty（>0）、est_price、est_amount、expect_date、purpose、suggest_supplier_id。

### 2.2 询比价单 price_inquiry

主表：inquiry_id、inquiry_no（`CG-XJ-…`）、pr_id（来源申请）、status、deadline（报价截止）。
报价子表 inquiry_quote：quote_id、supplier_id、item_id、quote_price、tax_rate、delivery_days、valid_days、remark。
比价结论：selected_quote_id（中标报价）、compare_note（比价说明）、历史均价偏离度（系统自动计算）。

### 2.3 采购订单 purchase_order（主表）

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| po_id | bigint PK | 是 | 主键 |
| po_no | varchar(32) | 是 | `CG-PO-{orgCode}-{yyyyMM}-{seq}` |
| supplier_id | bigint | 是 | 引用供应商；准入校验（R2） |
| contract_id | bigint | 条件必填 | 关联合同（无有效合同需特批标记） |
| pr_id / inquiry_id | bigint | 否 | 来源申请 / 比价单 |
| currency / tax_rate_default | - | 是 | 币种、默认税率 |
| total_qty / total_amount / tax_amount / total_with_tax | decimal | 是 | 数量/不含税金额/税额/价税合计（明细汇总） |
| payment_terms | varchar(256) | 是 | 付款条款（预付%/进度%/质保%） |
| receive_org_id / warehouse_id | bigint | 是 | 收货组织与默认收货仓库 |
| version | int | 是 | 变更版本号；变更超原金额 10% 重审 |
| status | enum | 是 | 通用状态机 + 执行态：部分入库/已入库/已关闭 |

明细 purchase_order_item：item_id、qty、price、tax_rate、tax_amount、amount_with_tax、delivery_date、received_qty（已入累计）、invoiced_qty（已开票累计）。

### 2.4 采购入库单 purchase_receipt

主表：receipt_id、receipt_no（`CG-RK-…`）、po_id、warehouse_id、arrive_date、check_type（数量清点/质量验收）、qc_result（合格/让步接收/拒收）、status。
明细：item_id、order_qty（订单剩余可入）、arrive_qty、qualified_qty、reject_qty、diff_type（NONE/SHORT/OVER/DAMAGE）、diff_reason、location_id（上架库位）。
管控：qualified_qty 累计 ≤ 订单行剩余量 + 超交容差（参数，默认 0，超交需单独审批）。

### 2.5 采购退货单 purchase_return

主表：return_id、return_no（`CG-TH-…`）、receipt_id、supplier_id、return_reason、duty_side（供应商/物流/我方）、refund_mode（退款/抵账）、status。
明细：item_id、qty（≤ 已入未退量）、price、amount。

### 2.6 采购对账单 purchase_statement

主表：stmt_id、stmt_no（`CG-DZ-…`）、supplier_id、period_start/end、order_amount、receipt_amount、invoice_amount、diff_amount、diff_note、confirm_status（待确认/已确认）、status。
明细 stmt_line：po_no、receipt_no、invoice_no（可空）、item_id、qty、price、amount、match_result（MATCH/QTY_DIFF/PRICE_DIFF/TAX_DIFF/NO_INVOICE）。

### 2.7 付款分期台账 payment_schedule（采购域视图）

schedule_id、po_id/stmt_id、phase（PREPAY 预付/PROGRESS 进度/RETENTION 质保）、plan_amount、plan_date、paid_amount、paid_date、status。财务付款回写本台账。

## 3. 业务规则与校验

| # | 规则 | 说明 |
|---|------|------|
| R1 | 审批匹配 | 申请提交时按金额区间匹配审批链（阈值参数化，默认 <5 万部门级 / 5-50 万子公司级 / >50 万集团级）；关联预算单据超预算时强制升级一级 |
| R2 | 供应商拦截 | 下单校验：status≠ACTIVE 阻断；资质到期阻断；BLACKLIST 全链阻断并提示 |
| R3 | 价格偏离 | 成交价 > 近 12 个月同品采购均价 ×(1+N%)（参数，默认 10%）时，强制填写偏离说明并审批链升级一级 |
| R4 | 入库限量 | 入库数量不得超订单剩余可入量；超交部分需「超交审批」方可入账；验收不合格数量自动转拒收登记 |
| R5 | 库存联动 | 入库单验收合格生效后即时增加库存（商品管理），同时生成应付暂估（财务） |
| R6 | 退货冲减 | 退货单生效联动库存扣减 + 应付冲减；退货金额 ≤ 原入库未结算金额 |
| R7 | 三单对账 | 对账单内存在 QTY_DIFF/PRICE_DIFF/TAX_DIFF 行时，必须逐行填写说明方可提交确认 |
| R8 | 付款上限 | 累计付款（含预付）不得超对账确认金额；质保金到期前不可释放 |
| R9 | 订单变更 | 变更金额超原订单 10% 或变更交期影响项目进度的，重新走原审批链 |
| R10 | 单据闭环 | 订单全部入库且对账确认后自动置「已完成」；未完成订单年末生成在途清单 |

## 4. 审批流配置建议

| 单据 / 事件 | 触发条件 | 建议审批链 | 说明 |
|------------|---------|-----------|------|
| 采购申请 | 金额 < 5 万 | 部门负责人 | 阈值参数化（系统管理统一维护） |
| 采购申请 | 5-50 万 | 部门负责人 → 子公司分管副总 | — |
| 采购申请 | > 50 万或超预算 | 部门负责人 → 子公司总经理 → 集团分管副总 | 超预算自动升级 |
| 询比价结果确认 | 全部 | 采购负责人 → 申请部门负责人 | 价格偏离触发时再升级 |
| 采购订单 | 全部 | 采购负责人 → 财务负责人（付款条款审核） | 金额 > 50 万加签子公司总经理 |
| 超交入库 | 全部 | 仓库负责人 → 采购负责人 | — |
| 采购退货 | 全部 | 与原订单同级审批链 | — |
| 对账单确认 | 存在差异行 | 采购负责人 → 财务负责人 | 无差异可配置为采购负责人单级 |

## 5. 权限点清单

**菜单**：采购管理 → 采购申请 / 询比价 / 采购订单 / 到货与入库 / 采购退货 / 采购对账 / 付款台账 / 采购报表。

**按钮**：新建、编辑、删除（草稿）、提交审批、驳回修改、变更、关闭订单、到货登记、验收确认、差异登记、退货发起、对账生成/确认、导出、打印、查看成本价。

**数据权限**：按组织树——申请人仅本人+本部门单据；采购岗可见所属公司全部；集团采购管理角色全量可见；项目类申请项目成员可见本项目。

**字段权限**：单价/成本价字段对仓库验收人员只读数量不可见价格（参数可配）。

## 6. 与其他模块联动

| 触发事件 | 目标模块 | 数据流 |
|---------|---------|-------|
| 入库单验收合格 | 商品管理 | 库存数量增加（移动加权平均价重算） |
| 入库单生效 / 退货生效 | 财务管理 | 生成应付暂估 / 红冲暂估凭证 |
| 对账单确认 | 财务管理 | 应付暂估转正式应付账款 |
| 进项发票登记 | 票据管理 | 发票与订单/入库单三单匹配，回写 invoiced_qty |
| 付款申请批准支付 | 财务管理 | 付款回写 payment_schedule 与订单结算状态 |
| 申请关联项目 | 项目管理 | 提交即占用项目预算（材料科目），驳回释放 |
| 订单关联合同 | 合同管理 | 归集合同已下单金额，执行看板更新 |
| 库存预警触发 | 商品管理 → 本模块 | 一键生成补货采购申请（source=STOCK_ALERT） |

## 7. 期初与历史数据处理

| 事项 | 处理方式 |
|------|---------|
| 在途订单 | 上线前已生效未执行完的采购订单，按「期初在途订单导入模板」录入（含已入数量、已付金额），审批后一次性生效，单据号段独立（期初前缀） |
| 期初应付 | 已入库未对账部分以「期初应付暂估」导入，与财务期初余额核对一致 |
| 历史单据 | 已完成历史单据不补录，保留原 Excel 台账备查；系统仅承接上线后新业务 |
| 价格基线 | 近 12 个月历史采购均价可通过导入形成「价格参考基线」，供 R3 偏离校验使用 |
