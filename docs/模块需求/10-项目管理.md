# 模块需求详设：10 项目管理（扩展模块）

> 对应《项目需求.md》4.10 ｜ 版本 v1.0 ｜ 2026-10-20
> 以项目为最小核算单元，承载项目档案、预算、产值与成本归集，支撑建筑劳务与材料供应业务的单项目盈利分析。项目节点映射《01-基础信息中心.md》组织架构第四级（PROJ）；预算占用与成本取数来自《02/03/04/06/07/11》各模块；合同额引用《09-合同管理.md》。

---

## 1. 功能清单（页面级）

| # | 页面 | 类型 | 核心功能 |
|---|------|------|---------|

| 3 | 项目详情 | 详情页（Tab） | 档案 / 预算 / 产值 / 成本归集 / 收支台账 / 关联合同与单据 / 结项报告 |

## 2. 核心实体与字段明细

### 2.1 项目档案 project

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| project_id | bigint PK | 是 | 主键 |
| project_code | varchar(20) | 是 | 项目编码，全局唯一（`XM-{yyyy}-{seq}`）；与组织树 PROJ 节点 org_code 映射 |
| project_name | varchar(128) | 是 | 项目名称 |
| project_type | enum | 是 | CONSTRUCT 工程施工/LABOR 劳务分包/SUPPLY 材料供应/OTHER 其他 |
| owner_name | varchar(128) | 是 | 业主（甲方） |
| contract_id | bigint | 条件必填 | 关联合同（合同额带出） |
| contract_amount | decimal(18,2) | 是 | 合同额 |
| start_date / end_date | date | 是 | 工期 |
| manager_id | bigint | 是 | 项目经理（引用 person） |
| org_id | bigint | 是 | 所属组织（公司），组织树第四级节点自动创建/关联 |
| status | enum | 是 | 筹备→在建→已竣工→已结项/已中止 |

### 2.2 项目预算 project_budget / 明细 budget_line

project_budget：budget_id、project_id、version、total_amount、status（编制中→已生效→调整中）、approved_at。
budget_line：line_id、budget_id、subject_type（LABOR 人工/MATERIAL 材料/MACHINE 机械/SUB 分包/MGMT 管理费用）、budget_amount、occupied_amount（占用，系统计算）、actual_amount（实际，系统计算）、exec_rate（执行率，系统计算）。
管控：预算调整生成新版本并留痕；occupied/actual 由业务单据驱动，禁止手工修改。

### 2.3 月度产值 project_output

output_id、project_id、month、progress_desc（形象进度）、output_amount（产值金额）、confirm_file_id（监理/甲方确认资料影像）、confirm_status（待确认/已确认）、status。
管控：产值确认后作为向甲方请款依据，联动销售管理/应收账款（R3）。

### 2.4 项目成本归集 project_cost（系统视图+快照）

cost_id、project_id、subject_type、source_type（采购入库/领用出库/劳务结算/费用报销/设备租金/盘亏分摊）、source_doc_no、amount、occur_date。
管控：全部取数自业务单据（R4），按月生成成本快照供报表加速。

### 2.5 项目收支台账 project_trans（系统视图）

收入侧：产值确认、销售出库（项目类订单）、设备租金（项目承租）、其他收入。
支出侧：材料（入库直耗+领用出库）、劳务（劳务结算+工资分摊）、机械（租赁结算）、分包、费用报销。
每笔记录含来源单据号，双向穿透。

## 3. 业务规则与校验

| # | 规则 | 说明 |
|---|------|------|
| R1 | 立项审批 | 项目立项必须审批；审批生效后自动在组织树创建/关联 PROJ 节点，项目编码全局唯一 |
| R2 | 预算硬控 | 关联项目的采购申请、劳务用工、费用报销提交时强制校验对应科目预算余额；超预算自动升级审批并标记；单据生效转实际、驳回释放占用（与财务 R5 同一套预算占用机制） |
| R3 | 产值请款 | 月度产值经确认（影像齐备）后方可生成请款/应收依据；产值累计 ≤ 合同额+变更额 |
| R4 | 成本自动归集 | 项目成本仅允许从业务单据自动归集，禁止手工平调；科目映射规则可配置（如领用出库→材料、劳务结算→人工） |
| R5 | 超支预警 | 科目执行率 > N%（参数，默认 90%）预警；>100% 标红并推送项目经理与财务负责人 |
| R6 | 项目归口 | 项目维度单据必须挂 project_id：采购（项目直耗）、销售（材料供应类）、劳务、报销、租赁，漏挂单据进入月度稽核清单 |
| R7 | 结项管控 | 项目结项前置：无在途单据、无未核销往来、成本归集截止；结项后项目只读，后续调整走专项审批 |
| R8 | 盈利穿透 | 项目盈亏表可逐层下钻至来源单据（与 4.12.5 追溯链一致） |
| R9 | 多公司项目 | 跨公司参与的项目，成本按单据所属公司归集、项目视图合并展示，内部结算依据联动财务 |
| R10 | 项目状态联动 | 项目中止/结项后，以其为归属的新单据（采购/用工/报销）阻断；在途单据限期完结或迁移 |

## 4. 审批流配置建议

| 单据 / 事件 | 触发条件 | 建议审批链 | 说明 |
|------------|---------|-----------|------|
| 项目立项 | 全部 | 子公司总经理 → 集团分管副总 → 集团总经理 | 合同额 > 阈值E 需集团办公会节点（可配置） |
| 预算编制/生效 | 全部 | 项目经理 → 财务负责人 → 子公司总经理 | — |
| 预算调整 | 调增 ≤ N% | 项目经理 → 财务负责人 | 调增 > N% 或超合同额：加签集团分管 |
| 产值确认 | 全部 | 项目经理 → 子公司分管副总 | 影像齐备前置 |
| 结项审批 | 全部 | 项目经理 → 财务负责人 → 子公司总经理 → 集团分管副总 | 附结项报告 |

## 5. 权限点清单

**菜单**：项目管理 → 项目列表 / 立项 / 预算 / 产值 / 成本看板 / 收支台账 / 核算分析 / 结项。

**按钮**：立项发起、预算编制/调整/生效、产值登记/确认、台账导出、结项发起、穿透查询、报表导出。

**数据权限**：项目经理与项目成员仅本项目（含其预算、成本、收支）；子公司管理层本公司全部项目；集团角色全量汇总。成本单价类字段按财务可见规则继承（材料成本价对非财务项目成员可隐藏，参数可配）。

## 6. 与其他模块联动

| 触发事件 | 目标模块 | 数据流 |
|---------|---------|-------|
| 项目类采购申请/入库 | 采购管理 | 预算占用（材料科目）；直耗入库归集项目成本 |
| 项目领用出库 | 物流/商品管理 | 材料成本按 avg_cost 归集 |
| 项目类销售出库/产值确认 | 销售管理 | 项目收入归集；应收账款挂项目维度 |
| 劳务用工/结算 | 人员管理 | 预算占用（人工科目）；人工成本归集 |
| 项目费用报销 | 财务管理 | 预算占用（管理费用科目）；费用成本归集 |
| 设备租赁结算 | 设备与租赁管理 | 机械成本归集（承租项目）/收入归集（出租归属） |
| 合同关联项目 | 合同管理 | 合同额、变更额、回款条款同步项目档案 |
| 项目维度凭证 | 财务管理 | 辅助核算 aux_project 自动带项目，项目核算与总账一致 |

## 7. 期初与历史数据处理

| 事项 | 处理方式 |
|------|---------|
| 在建项目期初 | 在建项目全量立项导入（免审批走期初通道），挂接组织树；累计已发生成本按科目导入期初值 |
| 期初预算 | 在建项目当前生效预算版本导入，已执行额度导入保证执行率连续 |
| 期初产值 | 累计已确认产值导入，作为后续请款与收入归集基线 |
| 历史项目 | 已竣工项目仅登记档案要素备查（不重建成本明细）；如需追溯保留原台账 |
| 期初核对 | 项目成本期初合计与财务对应科目余额核对一致后锁定 |
