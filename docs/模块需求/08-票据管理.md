# 模块需求详设：08 票据管理

> 对应《项目需求.md》4.8 ｜ 版本 v1.0 ｜ 2026-10-20
> 实现「进项、销项、费用、劳务」四类票据全生命周期管理，与业务单据一一关联。数电票适配按全面数字电子发票规范执行；三单匹配联动《02-采购管理.md》《03-销售管理.md》，报销查重联动《07-财务管理.md》，劳务票据联动《06-人员管理.md》。

---

## 2. 核心实体与字段明细

### 2.1 发票主表 invoice（四类共用，type 区分）

| 字段 | 类型 | 必填 | 说明 / 校验 |
|------|------|------|------------|
| invoice_id | bigint PK | 是 | 主键 |
| invoice_type | enum | 是 | INPUT 进项/OUTPUT 销项/EXPENSE 费用/LABOR 劳务 |
| is_digital | bit | 是 | 是否数电票 |
| invoice_code | varchar(12) | 纸票必填 | 发票代码（数电票为空） |
| invoice_no | varchar(20) | 是 | 发票号码；唯一键 = code+no（纸票）/ 20 位号码（数电票），R1 |
| invoice_date | date | 是 | 开票日期 |
| seller_name / seller_tax_no | varchar | 是 | 销售方名称/税号 |
| buyer_name / buyer_tax_no | varchar | 是 | 购买方名称/税号（本集团税号自动带出） |
| amount / tax_rate / tax_amount / total_amount | decimal | 是 | 不含税金额/税率/税额/价税合计 |
| check_status | enum | 是 | UNCHECKED 未查验/VALID 真/INVALID 伪/ABNORMAL 异常（作废/红冲） |
| check_at / check_times | datetime/int | 否 | 查验时间与次数 |
| deduct_status | enum | 进项用 | 未认证/已勾选/已认证抵扣；deduct_period 抵扣期间 |
| source_file_id | bigint | 数电票必填 | XML/OFD 版式源文件（电子会计凭证存档，R4） |
| image_file_id | bigint | 是 | 票面影像 |
| status | enum | 是 | 正常/已红冲/已作废/已归档 |

### 2.2 发票与单据关联 invoice_biz_link

link_id、invoice_id、biz_type（采购订单/入库单/报销单/销售订单/出库单/对账单/劳务结算单）、biz_no、link_amount（关联金额，支持一张票拆分关联多单）。
管控：进项票关联金额累计 ≤ 发票价税合计；双向可追溯（票查单、单查票）。

### 2.3 开票申请单 invoice_apply

apply_id、apply_no（`PJ-KP-{orgCode}-{yyyyMM}-{seq}`）、customer_id、biz_ref_no（销售订单/对账单）、apply_amount、invoice_kind（专票/普票/数电票）、buyer_info（快照）、merge_split（合并/拆分说明）、status。
管控：申请金额 ≤ 关联单据可开票余额（订单金额-已开票累计）。

### 2.4 红字申请 red_apply

red_id、red_no（`PJ-HZ-…`）、original_invoice_id（原蓝字发票）、reason、red_info_no（红字信息表编号）、status。审批生效后原票置「已红冲」，生成红字发票记录（金额为负）。

### 2.5 劳务票据关联 labor_invoice_link

在 invoice_biz_link 基础上增加：settle_no（劳务结算单号）、tax_payment_cert_file_id（完税凭证影像）、verify_status。结算单可付款前置校验：发票+完税凭证齐（联动 07 模块付款挂起）。

### 2.6 三单匹配结果 match_result

match_id、match_type（PURCHASE 采购三单/SALE 销售三单）、po_no/so_no、receipt_no/delivery_no、invoice_id、match_status（MATCH/QTY_DIFF/PRICE_DIFF/TAX_DIFF/NO_INVOICE/OVER_INVOICE）、diff_note、handle_status（未处理/处理中/已办结）、handler_id。

### 2.7 归档 archive / 借阅 borrow

archive：arc_id、arc_no（归档号，规则 `GD-{yyyy}-{seq}`）、invoice_id、location（物理存放位置）、box_no、archived_at、archived_by。
borrow：borrow_id、arc_id、borrower_id、borrow_date、expect_return、actual_return、status（借出中/已归还/超期）、approved_by。

## 3. 业务规则与校验

| # | 规则 | 说明 |
|---|------|------|
| R1 | 全局查重 | 发票唯一键（纸票代码+号码 / 数电票 20 位号码）租户内唯一；重复录入阻断并提示已存在记录与关联单据 |
| R2 | 真伪必验 | 进项/费用/劳务发票入账前必须完成查验；查验为伪/异常（作废、已红冲）发票禁止入账并推送预警 |
| R3 | 一票一报 | 费用类发票被报销单引用后锁定；其他报销单引用时查重接口返回已报销状态并阻断（联动财务 R3） |
| R4 | 数电票归档 | 数电票必须保存 XML/OFD 版式源文件（仅保存 PDF/图片不合规）；源文件与发票记录不可删除，满足电子会计凭证存档要求 |
| R5 | 开票限额 | 开票申请金额 ≤ 订单可开票余额；超额阻断；合并开票限同一客户同一税率 |
| R6 | 红冲管控 | 红冲必须关联原蓝字发票，红冲金额 ≤ 原票可红冲余额；红字申请审批通过后方可开具 |
| R7 | 三单匹配 | 进项：采购订单↔入库单↔发票数量、单价、税率比对；销项：销售订单↔出库单↔发票比对；不符项自动进异常清单，限期 N 天处理 |
| R8 | 劳务票控 | 劳务结算单对应劳务发票与完税凭证未登记核验完成，结算款挂起不付（联动 06/07 模块） |
| R9 | 认证时效 | 进项发票勾选认证按抵扣期间汇总；逾期未认证发票清单月度预警 |
| R10 | 归档锁定 | 归档后票据只读，修改需拆档审批；借阅超期未还自动预警至借阅人与部门负责人 |
| R11 | 影像强制 | 所有票据必须上传票面影像；费用票据无影像禁止提交报销 |
| R12 | 双向追溯 | 任意发票可穿透至关联业务单据、审批记录、凭证；任意单据可反查关联票据与源文件 |

## 4. 审批流配置建议

| 单据 / 事件 | 触发条件 | 建议审批链 | 说明 |
|------------|---------|-----------|------|
| 开票申请 | 全部 | 销售负责人 → 财务负责人 | 关联对账单已确认可配置为财务单级 |
| 红字发票申请 | 全部 | 业务负责人 → 财务负责人 | 金额 > 阈值加签集团分管 |
| 异常匹配处理（差异确认） | 全部 | 业务负责人 → 财务负责人 | 逐笔说明后办结 |
| 发票作废（销项） | 全部 | 财务负责人 | 当月未交付方可作废 |
| 拆档修改 | 全部 | 财务负责人 → 集团分管副总 | R10 |
| 借阅申请 | 全部 | 票据管理员 → 财务负责人 | 超期归还需说明 |

## 5. 权限点清单

**菜单**：票据管理 → 进项发票 / 销项发票 / 开票申请 / 红字申请 / 费用票据 / 劳务票据 / 三单匹配 / 税务台账 / 票据归档 / 借阅管理。

**按钮**：采集录入、OCR 识别、查验、勾选认证、开票申请/登记、交付登记、红冲发起、匹配处理、归档、借阅发起/归还、台账导出、源文件下载（留痕）。

**数据权限**：票据管理员与财务按公司范围全量；业务人员仅可见本人/本部门关联单据的票据；税务台账按公司+集团两级。

**字段权限**：源文件下载与影像查看全部留痕（查看人/时间/IP），满足审计要求。

## 6. 与其他模块联动

| 触发事件 | 目标模块 | 数据流 |
|---------|---------|-------|
| 进项发票登记+查验通过 | 采购管理 | 回写订单/入库单已开票信息；三单匹配执行 |
| 进项发票认证抵扣 | 财务管理 | 抵扣税额进入应交税费核算口径，月度汇总至税务台账 |
| 开票申请批准 | 销售管理 | 开票登记回写订单 invoiced_qty 与可开票余额 |
| 报销单提交挂票 | 财务管理 | 查重接口实时校验；报销生效后发票锁定 |
| 劳务发票/完税凭证核验完成 | 人员管理/财务管理 | 解除结算款挂起，允许付款 |
| 匹配异常办结 | 采购/销售 | 差异处理结果回写业务单据备注 |
| 红字发票生效 | 销售/财务管理 | 冲减对应应收与销项税额 |
| 归档/借阅动作 | 审计体系（架构规格） | 归档号、借阅轨迹进入审计日志 |

## 7. 期初与历史数据处理

| 事项 | 处理方式 |
|------|---------|
| 期初进项票 | 上线前已取得未认证发票批量导入（含查验状态），纳入认证管理 |
| 期初销项票 | 已开未交付/未回款发票登记，关联期初在途销售订单 |
| 历史票据 | 已完成抵扣/报销的历史票据不补录影像；按税务要求保留原纸质归档，系统登记归档索引（可选） |
| 数电票历史文件 | 上线后接收的数电票源文件必须全量归档；历史数电票源文件补传（如可获取） |
| 归档初始化 | 现有实物票据库房/柜位信息导入为存放位置字典，期初归档号段设定 |
